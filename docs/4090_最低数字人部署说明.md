# RTX 4090 · DeepSeek + DUIX 最低显存数字人补丁 V1.2

## 1. 与之前版本的关系

本 ZIP **只是增量补丁**，不是独立完整版。将里面的文件按相同相对路径覆盖到此前 `VoiceCompanion_DeepSeek_4090_V1.1/` 项目根目录。

**修改/覆盖：**

- `web/app.js`：修复分段视频之间出现生成空档时，任务编号被提前清理，导致第二段及后续视频停止播放的问题。
- `tools/configure_upstream.py`：使用 CPU 语音识别 + GPU TTS 配置，并兼容原有项目目录、QQ 白名单修补；重复运行不会重复插补。
- `tools/download_models.py`：修复原版本 `snapshot_download` 导入遗漏。
- `.env.example`：最低显存参数模板（**不会覆盖已有 .env**）。
- `START_DUIX.cmd`：增加 Docker/GPU 启动前检查，避免误认为容器已可以推理。

**新增：**

- `SELECT_4090_VIDEO_MIN.cmd`：设置 0.6B 声音克隆、FunASR CPU、DUIX 按需启用。
- `SELECT_4090_VIDEO_QUALITY.cmd`：切换到声音更好的 1.7B，其他不变。
- `CHECK_DIGITAL_4090.cmd`：GPU、Docker、DUIX HTTP、独立应用接口、形象素材路径检查。
- `tools/apply_digital_profile.py`
- `scripts/start_duix.ps1`、`scripts/check_duix.ps1`
- `tests/test_digital_profile.py`：离线回归测试。

**注意：**保留原版 `docker/compose-4090.yml`，是**仅数字人生成容器**：`guiji2025/duix.avatar:latest`，宿主 `127.0.0.1:9000` 到容器 `8383`，不额外运行 DUIX 的 FishSpeech / ASR 容器。

## 2. 目标配置（4090 上无需 ComfyUI）

```env
TTS_SIZE=0.6
STT_DEVICE=cpu
TTS_DEVICE=cuda
DIGITAL_HUMAN_ENABLED=0
```

- **DeepSeek API**：云端 LLM；本地 LLM 显存约 0GB。
- **FunASR**：CPU，减少显存，但语音识别速度取决于 CPU。
- **Qwen3-TTS 0.6B Base**：显卡上进行声音克隆；需要自己的合法参考音频。
- **DUIX**：独立 Docker GPU 容器；运行 `START_DUIX.cmd` 后，在浏览器内打开 **数字人口播** 开关即可使用；关闭时桥接会按配置停止容器。`DIGITAL_HUMAN_ENABLED=0` 仅表示**启动默认关闭**，不是取消视频功能。
- **不运行 ComfyUI**：4090 的 24GB 显存由本系统独占，若音质优先可切换到 1.7B，不必坚持极限省显存。

> **显存预期**：之前提到的 8–12GB 是粗略规划值，**不是硬上限或实测数据**。DUIX 镜像的实际常驻显存、TensorRT/PyTorch 初始化开销、视频分辨率、模型驻留叠加后可能超过 12GB。推荐直接用 `nvidia-smi` 核对峰值和稳定状态；4090 的 24GB 是可用总显存。

## 3. 第一次运行（Windows）

1. 安装 Python 3.11、NVIDIA 显卡驱动、Docker Desktop（WSL2 引擎）。运行 `nvidia-smi` 确认是 RTX 4090。
2. 将补丁 ZIP **解压覆盖到原 V1.1 项目根目录**（其他未变化的文件保留）。
3. 双击 `STOP.cmd`，然后 `SELECT_4090_VIDEO_MIN.cmd`。
4. 双击 `INSTALL.cmd`：安装本地 Python 语音环境并下载 FunASR / Qwen3-TTS 0.6B / Silero（可能需要较多磁盘）。
5. 在 `voices/你的音色/` 放入 `ref_audio.wav` 与逐字匹配的 `ref_text.txt`，运行 `CONFIGURE_VOICE.cmd`。
6. 按 DUIX 官方方法准备**可以被其模型正确使用的数字人形象素材**，将用于调用的模型/形象文件放在 `data/duix/temp/my_avatar.mp4`。**普通随手拷贝的 MP4 不保证符合 DUIX 输入要求**；需要先通过 DUIX 官方流程创建/预处理形象。
7. 启动 Docker Desktop，双击 `START_DUIX.cmd`，等待服务真正就绪，再双击 `START.cmd`。
8. 网页打开 `http://127.0.0.1:8765/`，打开 **声音朗读**、**数字人口播**，与 AI 说话。
9. 运行 `CHECK_DIGITAL_4090.cmd` 检查服务，进行一次实际短句生成，确认画面+声音同步、连续分段以及 `nvidia-smi` 峰值。

## 4. 常见问题

- **网页有文字、无声音**：检查 `SMOKE_TTS.cmd`、`voices/` 音色文件、下载的 0.6B Base 模型。
- **数字人按钮打开但视频不生成**：运行 `CHECK_DIGITAL_4090.cmd`，查看 `docker logs duix-avatar-gen-video --tail 100`；检查 DUIX 原生模型/形象是否已正确预处理。
- **Docker 可启动但报 CUDA/TensorRT 错**：使用 RTX 40 系通用镜像，不要直接将 RTX 5090 特制 TensorRT 镜像覆盖此配置；检查容器 GPU 可见性。
- **只播放第一段**：本补丁修复该状态问题。请刷新浏览器，确认已经覆盖 `web/app.js`。
- **数字人等待比纯语音久**：这是 DUIX 分段视频生成架构的性质，不能保证逐帧实时低延迟。
- **出现 OOM**：通过 `STOP_DUIX.cmd` 停止容器；若语音仍占用过多显存，结束服务后确认显存释放并核对同时运行的其他 GPU 进程。
- **希望提高声音质量**：运行 `STOP.cmd` → `SELECT_4090_VIDEO_QUALITY.cmd` → `INSTALL.cmd` → `CONFIGURE_VOICE.cmd` → `START.cmd`。这时显存可能更高。
