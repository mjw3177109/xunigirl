# V1.6.1：Kaggle 免费 GPU 小雅图片生成口播视频（实验）

本实验输入是已发布的小雅人物 PNG 与 Kaggle T4 实测的 `voices/xiaoya/ref_audio.wav`。通过公开的 SadTalker 模型尝试生成包含 **音轨和视频轨** 的 MP4，作为数字人视频链路的免费 GPU 可行性验证。

- 提交 Notebook：`kaggle/xiaoya_t4_avatar_video_pilot.ipynb`
- GitHub 工作流：`Kaggle Xiaoya Avatar Video Pilot`
- 结果验收工作流：`Collect Kaggle Xiaoya Avatar Video Pilot`
- Kaggle Notebook： https://www.kaggle.com/code/mjw3177109/xunigirl-xiaoya-avatar-video-pilot
- 成功输出期望：`xiaoya_video_results/xiaoya_talking_pilot.mp4`、`video_report.json`、推理日志。

## 限制

1. 这是 SadTalker 图片驱动视频实验，**不是 DUIX 生成的 MP4**；不能当作 DJI/4090 DUIX 完成验收。
2. SadTalker 为旧项目，现代 Kaggle Python/Torch 依赖可能不兼容；要以实际运行结果为准。
3. 256 分辨率仅用于链路测试，不是高清商品视频。
4. Kaggle T4 免费配额有限，结果按成功/失败真实记录，不允许复制图像合成伪视频来冒充模型推理。
5. 人物是生成素材，音色是人工合成，不应将其冒充真人肖像或声音。
6. 用户最终版本依旧是 4090 + DUIX，本 Notebook 仅验证免费 GPU 上的独立图片口播路线。
