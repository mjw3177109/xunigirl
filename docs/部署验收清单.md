# RTX 4090 独立版验收清单

- [ ] `py -3.11 --version` 可用、Windows 10/11 x64；检查存储空间。
- [ ] 运行 `INSTALL_TEXT_ONLY.cmd`，创建 `.env` 和 `.venv`，成功输出完成提示。
- [ ] 填写有效 DeepSeek API Key；`START.cmd` 打开 `http://127.0.0.1:8765/`。
- [ ] 网页 DeepSeek 灯显示已配置；输入文字能看到流式回复、聊天记录保存。
- [ ] 新建会话、刷新网页、打开旧会话、删除会话均正确。
- [ ] 发送长回复时点击停止，确认无更多文字流入，未提交残留音频。
- [ ] 运行 `INSTALL.cmd`；模型和依赖下载成功。`CHECK.cmd` 显示 FunASR、Qwen3-TTS 路径有效。
- [ ] 有授权的人声素材与逐字文稿，放在 `voices/<your_voice>/` 并运行 `CONFIGURE_VOICE.cmd`。
- [ ] `GET /voice/api/health` 返回 200；麦克风录音后能识别中文。
- [ ] 语音自动朗读无内容重复、相邻段依次播完。手动停止无旧语音回放。
- [ ] 可选：GPU、Docker Desktop、DUIX 模型资源均正常；`docker logs` 无 TRT/ONNX CPU fallback。
- [ ] 可选： `data/duix/temp/my_avatar.mp4` 存在，容器在 9000 端口可响应，网页数字人口播完成生成与播放。
- [ ] GPU 空闲、语音、数字人三种模式分别记录 `nvidia-smi` 显存数值；不可用推测估值替代。
- [ ] `STOP.cmd` 仅终止本项目后端；`STOP_DUIX.cmd` 可关闭可选容器。
- [ ] `.env`、音色、个人视频、SQLite 数据库没有进入公开仓库。

如安装命令失败，保留控制台错误、`data/server.stderr.log` 和（适用时）`docker logs duix-avatar-gen-video` 用于排障。
