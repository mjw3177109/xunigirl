# RTX 4090 数字人 V1.4 部署前自检

本补丁针对 [xunigirl](https://github.com/mjw3177109/xunigirl) 完整 V1.3，属于增量修复，不覆盖声音 WAV、人物图、API Key 或其他模型文件。

## 运行方法

1. 首次安装先运行 `INSTALL.cmd`。
2. 配置本地 `.env` 的 DeepSeek API Key。不要上传 `.env`。
3. 双击 `PRECHECK_4090.cmd`，会显示 `PASS / WARNING / FAIL` 并生成 `data/preflight_4090.json`。
4. 运行 `GENERATE_XIAOYA_VOICE.cmd` 可把预置机械样音换成自然合成音色；检查报告会提示当前是否仍为试听音。
5. 准备好 DUIX 已正确预处理的形象视频 `data/duix/temp/my_avatar.mp4`，启动 Docker Desktop，再双击 `START_DUIX.cmd`。
6. 再运行 `PRECHECK_4090.cmd`，看 `gpu`、`docker`、`duix_container`、`avatar_video` 是否通过。
7. 双击 `START.cmd` 打开网页，先测试文字和语音，再测试一小段真实数字人口播，运行 `CHECK_DIGITAL_4090.cmd`。

也可在虚拟环境的 Python 下单独检查：

```powershell
.venv\Scripts\python.exe tools\preflight_4090.py --mode text
.venv\Scripts\python.exe tools\preflight_4090.py --mode voice
.venv\Scripts\python.exe tools\preflight_4090.py --mode digital --strict
```

## 说明

- 自检不会使用 DeepSeek API，不消耗 Token，也不运行 GPU 负载。
- 配置和运行时的数字人开关现在不会在每次 `CONFIGURE_VOICE.cmd` 时被覆盖。
- 仓库中预置的是机械合成参考 WAV，需要在你的 4090 上生成正式甜美音色；图像 PNG 不能直接代替 DUIX 预处理过的口播 MP4。
- JSON 报告记录硬件型号、状态和不涉及机密的检查信息，不包含 API Key、聊天历史或原始语音内容。
- `PASS` 不代表高质量数字人真实生成成功。需要看最终 MP4 的人脸、口型、时长、声音与显存峰值。
