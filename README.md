- 本地完整包：V1.3（含小雅 PNG 人物图、参考声音 WAV、安装启动脚本）

- DeepSeek API Key 填写在本地 `.env`，禁止提交到 GitHub
- 完整音视频部署需要 NVIDIA GPU、Python 3.11 与 Docker Desktop
